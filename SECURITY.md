# Security policy

Rx Vault stores people's medical records, so security reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through GitHub:
**Security → Report a vulnerability** on this repository.

Please include the steps to reproduce and what an attacker could access. You will get a reply within 7 days.

## Scope

- The web app at https://rx-vault.expo.app and the code in this repository.
- Row-level security policies and storage policies in `supabase/migrations/`.

Please test only with accounts you created yourself, and never access or change other people's data.
